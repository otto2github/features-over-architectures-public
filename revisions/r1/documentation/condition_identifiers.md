# Condition identifiers

Public directory names are descriptive. Stored identifiers inside CSV/NPZ and source configuration remain exact join keys. In particular, `V26|...` denotes the predecessor benchmark reference, not an extra fitted condition. `A` is the document-key supervision purge; `B` is donor completion over the three fixed worlds; `B0` is FIN87 deletion; `C` is the three-flag RF.

Stored-message GNN results and reverse-message references are not interchangeable. In predecessor directional records, ORIGINAL/STORED GNN identifiers denote the stored-message rerun; REVERSE denotes the design-aligned graph reference. MLP identifiers have no message-direction treatment. Full/D/O share the stated population rules; D/O partition positives while retaining common negatives.

The 42-input GNN extension uses original B0 supervision, not A-purged supervision. Keep original run identifiers, model labels, feature labels, population keys and numerical arrays when reusing the evidence. A cleaner directory name is not a new scientific condition.

Detailed inherited mappings are in `documentation/predecessor/condition_identifiers.md`.
