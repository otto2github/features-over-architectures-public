# E7 source scope and reproduction boundary

The E7 addition is a separately specified twenty-fit comparison on the original 129-input M11 representation: two models, five paired seeds and two contemporaneous conditions. The twenty new fits and 2,000 fixed-score paired bootstrap draws are distinct from the retained 105-fit sensitivity programme, strict replay and ten-fit 42-input extension. Earlier results were visible when this extension was specified.

The graph adds 265,383 annual issuer–record incidences and 62,920 separate zero-feature supporting nodes. Both conditions share 366,695 nodes. This record-level proxy leaves global legal-entity ID semantics, missing IDs, renames/collisions, transaction amounts/direction and historical disclosure timing unresolved. It adds neither validated transaction events nor independent positive outcomes.

`documentation/e7_source_map.json` gives current paths. The scientific reader protocols are translated publication derivatives; original protocol hashes and original-to-public source identities are preserved in `provenance/source_hashes.json`. Original `RUNNER_IDENTITIES.json` binds the executed private source package, not every publication copy. Source paths in publication records have semantic placeholders; source hashes, sizes, numerical metrics, locking statuses, model/seed tokens and frozen rules are preserved.

The public check recomputes per-fit group means/SDs and paired point differences/SDs, verifies populations/budgets and Full/D/O identities, and checks recorded fit/lock/determinism/interval contracts. It cannot reconstruct labels, model probabilities, checkpoint hashes against private checkpoint files, or interval quantiles from undistributed E7 draw arrays. Remote execution assertions are source-bound records, not independent re-execution. It does not claim global entity-matching validation, exact empirical reproduction from current vendor downloads or licensing certification.

`code/e7/run_reader.py` is portable and runs aggregate verification by default. Construction/training source copies are retained for inspection under `code/e7/construction/` and `code/e7/training/`; their private paths are placeholders. Independent empirical execution needs separately authorized exact inputs, configuration files and the recorded GPU environment. Public checks import no Torch/PyG and perform no fitting, inference, threshold selection, new empirical resampling or network access.
