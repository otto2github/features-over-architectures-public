# Historical message-loader reference

`gnn_baseline_v1_1.py` is a byte-verified reconstruction of a retained 621-line source. Lines 183–194 append the reverse of each annual edge and repeat relation labels. Its original hash is recorded in SOURCE_IDENTITY.json. This is historical source evidence, not the runner used for the revised endpoint.

The original submission's public GitHub release, inspected at commit `a6acbb2414a36cc987c6c0132c6df643f9dd519b`, identifies the same-named runner with the main benchmark and implements the same reverse expansion. The public copy has publication adaptations and is not asserted to have the recovered copy's byte hash. Neither the README nor matching algorithm text uniquely binds every original table entry to the exact executed version.

The reconstructed-endpoint `code/formal_rerun_core.py` passes stored directions without generic reversal. The post-hoc direction experiment appends reverses to that revision-stage control. Consequently, its effect is not a measurement of a direction defect proven to have existed in every original-submission run.

This file is distributed for inspection only. Its original project dependencies and historical inputs are not recreated by the current package. No historical training is part of the public checks.
